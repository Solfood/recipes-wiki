# DEC-0002: Retire the MkDocs site; recipes move to Mealie

- Date: 2026-11-10
- Status: accepted
- Owner: Solfood
- Marker: RW-ARCH-0003 (import: RW-DATA-0002)
- Supersedes: N/A

## Context

The wiki is a static MkDocs site served from the homelab laptop at
`recipes.local:8082` (nginx `recipes-web`, rsynced by homelab
`laptop/deploy-site.sh`). Adding or editing a recipe means editing Markdown on
the Mac, building, and redeploying. The owner chose to replace it with
[Mealie](https://mealie.io), a self-hosted recipe manager edited in the browser.

## Intake

- Objective: recipes live in Mealie at the same address; nothing is lost.
- In scope: one-shot import of the 10 recipes (`scripts/import_to_mealie.py`);
  homelab compose swaps `recipes-web` for `mealie` on `:8082`; this repo stops
  being deployed.
- Out of scope: deleting this repo or its Markdown (kept as the archive);
  ingredient parsing into Mealie foods/units (left as free-text notes).
- Risk class: medium — critical asset `recipe_content` moves to a new system
  (read-only here; the Markdown is untouched).
- Dependencies: Solfood/homelab PR adding the `mealie` service.
- Expected evidence: dry-run word-coverage check passes; import into a scratch
  Mealie succeeds and re-runs idempotently; read-back shows sections, steps,
  notes and tables intact.

## Options Considered

1. **Keep MkDocs** — status quo; editing stays a build-and-deploy chore.
2. **Mealie, recipes re-typed by hand** — error-prone for 10 detailed recipes.
3. **Mealie + scripted import** (chosen) — deterministic, re-runnable,
   checked word-for-word against the source.

## Decision

Mealie v3 replaces the site at `recipes.local:8082`. Recipes are imported by
`scripts/import_to_mealie.py`; after cutover Mealie is the source of truth and
this repo is archive-only.

## Mapping

Ingredient groups (`### X` / `**X:**`) → Mealie ingredient section titles;
ingredient lines → free-text notes (emphasis/links stripped). `### N. Title` /
`### Step N:` → titled steps; other `###` groups → their numbered items as
steps, first titled. `Notes`/`Tips`/`Calculating…`/`Troubleshooting`
subsections, extra `##` sections (Equipment, Cut Options), and callouts that
close the Method → recipe notes (Markdown, tables kept). Callouts mid-method
stay in their step as blockquotes. Recipe Details → yield/prep/cook; other
detail lines → a "Details" note. Folder → category; `*Tags:*` → tags.

## Threat model (Gate 2)

| Threat | Mitigation |
|---|---|
| Mealie ships a default admin `changeme@example.com` / `MyPassword` | Change it on first login (cutover step); Mealie's About page flags it while it remains |
| Anyone on the LAN creates an account | `ALLOW_SIGNUP=false` |
| Exposure beyond the LAN | No port-forward; served on `:8082` like the old site |
| Data loss in Mealie | SQLite in homelab `appdata/mealie` (+ Mealie nightly backups); this Markdown remains a full re-importable copy |

## Rollback Plan

Revert the homelab PR (restores `recipes-web`), then
`./laptop/deploy-site.sh recipes` from the reverting commit's tree. The
Markdown here was never modified.
